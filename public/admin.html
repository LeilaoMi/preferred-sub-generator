节点配置

节点参数（UUID、SNI、Host、路径、TLS）来自 Cloudflare Pages 的环境变量（对标竞品做法），项目内不再保存任何模板。修改请去 Cloudflare Dashboard → Pages 项目 → 设置 → 环境变量，改完自动重新部署生效。

环境变量：VLESS_UUID / VLESS_SNI / VLESS_HOST / VLESS_PATH / VLESS_PORT / VLESS_TYPE / VLESS_SECURITY

请先填写管理 token，或用 /admin.html#token=你的token 打开。
